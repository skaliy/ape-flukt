# Ape-Flukt! (Monkey Escape!)

**Play it here: https://ape-flukt.vercel.app/**

A fun weekend project built with my niece!

## What is this?

A mobile-friendly arcade game where you control a monkey escaping from trolls while collecting bananas. Simple, chaotic, and surprisingly addictive.

## How to Play

- **Collect bananas** to advance through levels
- **Avoid the trolls** - they're chasing you!
- **Use freeze traps** when things get too hectic
- **Sprint** to make quick escapes (but watch your stamina)

## Controls

- **Desktop**: Mouse to move, click to sprint, spacebar for freeze trap
- **Mobile**: Touch joystick to move, buttons for sprint and freeze

## Tech

- Vanilla JavaScript + Canvas
- Supabase for the leaderboard
- No frameworks, no build tools, just vibes
